# Machine Learning Growth System

个人机器学习成长学习系统的 Phase 2 可运行版本。

## 当前功能

- 数据驱动的每日学习任务列表
- 学习详情页（概念、数学、工程案例、PyTorch 代码、常见错误）
- 完成学习按钮
- 使用 LocalStorage 保存学习完成、测试、评分和学习时间状态
- 章节知识测试与即时答案反馈
- 每日掌握度 1–5 星评分
- 当月学习日历与连续学习天数
- 今日与累计学习时间统计
- 电脑与手机响应式布局

## 运行方式

浏览器出于安全限制，直接双击 `index.html` 时可能不允许读取 JSON。请在本目录启动一个静态服务器：

```powershell
python -m http.server 8000
```

然后访问 `http://localhost:8000`。

## 添加课程

1. 复制 `data/day001.json` 并按天数命名，例如 `day002.json`。
2. 修改课程内容。
3. 在 `js/app.js` 顶部的 `COURSE_FILES` 数组中加入新文件路径。

学习记录保存在当前浏览器的 `ml-growth:v2:progress` 键中，旧版 Phase 1 数据会在首次打开时自动迁移。即使网站公开发布，记录仍保存在每台设备各自的浏览器中，暂不支持跨设备同步。
